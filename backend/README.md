# Основы Node.js, Express и MongoDB (13 спринт)

## Проектная работа: «Web-ларёк. Тёмная сторона» (бэкенд)

> ### Стек
> Node.js + Express.js + TypeScript + MongoDB

### Структура:

- src/ — корневой каталог
- src/controllers/ — каталог контроллеров
- src/errors/ — каталог кастомных классов ошибок
- src/middlewares/ — каталог мидлваров
- src/models/ — каталог моделей
- src/public/ — каталог служебных файлов
- src/routes/ — каталог роутов
- src/utils/ — каталог с утилитами

### Важные файлы:

- src/app.ts — основная логика сервера
- src/config.ts — экспорт конфигурационных данных

### Установка и запуск

Для установки и запуска проекта необходимо выполнить команды:

```
npm install
npm run dev
```
